## Software — Official Sources

[1] Siril Official Website. https://siril.org/  
Tier 2. Confirmed Siril is a free astronomical image processing tool, GPL v3, cross-platform.

[2] Siril 1.4.2 Release Notes (2026-02-18). https://siril.org/download/2026-02-18-siril-1-4-2/  
Tier 2. Confirmed v1.4.2 release: GPU manager improvements, Python scripting enhancements, SPCC caching, UCRT64 experimental Windows build raising file limit to 8,192.

[3] Siril 1.4.0 Release Notes (2025-12-05). https://siril.org/download/2025-12-05-siril-1-4-0/  
Tier 2. Major release adding Drizzle, ICC color management, SPCC, Python scripting IDE.

[4] Siril Official Tutorials Index. https://siril.org/tutorials/  
Tier 2. Lists 24 tutorials (difficulty 0–5), including first steps, scripts, manual preprocessing, StarNet integration, PixelMath, GHS, mosaics, comets, pySiril. References Deep Space Astro and BorealisLite YouTube channels.

[5] Siril GitLab Repository. https://gitlab.com/free-astro/siril

[6] Siril JOSS Paper (2024). https://ui.adsabs.harvard.edu/abs/2024JOSS....9.7242R/abstract  
Tier 1. Peer-reviewed publication in Journal of Open Source Software.

[7] GraXpert Official Website. https://graxpert.com/  
Tier 2. AI-based gradient extraction, denoising, deconvolution. Open source, BSD-3-Clause. Windows/macOS/Linux. Discord community at discord.gg/DarkMatters.

[8] GraXpert GitHub Releases. https://github.com/Steffenhir/GraXpert/releases  
Tier 2. Latest stable: v3.0.2 (2024-05-03). v3.1.0rc2 adds stellar deconvolution AI model. v3.0.0 introduced AI denoising, redesigned UI, GPU acceleration.

[9] StarNet V2 Download Page. https://www.starnetastro.com/download/  
Tier 2. CLI v2.0.0, PixInsight plugin v2.1.2-0127. Windows/macOS/Linux. Neural network star removal.

[10] StarNet GitHub Repository. https://github.com/nekitmm/starnet  
Tier 2. Open source repository for StarNet neural network.

[11] KStars Official Website. https://kstars.kde.org/  
Tier 2. Full planetarium + observatory automation. GPL v2+. Linux/macOS/Windows. Ekos handles camera control, autofocus, autoguiding, plate solving.

[12] PHD2 Official Website. https://openphdguiding.org/  
Tier 2. v2.6.14 (user guide dated 2025-12-09). BSD license. Multi-star guiding, Guiding Assistant.

[13] DeepSkyStacker Official Website. https://deepskystacker.com/  
Tier 2. BSD 3-Clause. v6.1.0 added Linux and macOS support.

[14] DeepSkyStacker GitHub. https://github.com/deepskystacker/DSS  
Tier 2. Open source repository.

[15] ASTAP Official Website. https://www.hnsky.org/astap.htm

[16] NINA Official Website. https://nighttime-imaging.eu/  
Tier 2. v3.2 (2025-11-12). Mozilla Public License 2.0. Windows only. Full imaging sequence automation.

[17] INDI Library. https://indilib.org/about/ekos.html  
Tier 2. Hardware abstraction layer for astronomical equipment. GPL.

[18] Astrometry.net. https://nova.astrometry.net/

## Data Archives — Institutional

[19] MAST Portal (STScI). https://archive.stsci.edu/  
Tier 1. Hosts all JWST and Hubble data. FITS format. No registration required for public data.

[20] MAST JWST Data Access. https://archive.stsci.edu/missions-and-data/jwst  
Tier 1. Four processing stages: Stage 0 (raw FITS), Stage 1 (count-rate), Stage 2 (fully calibrated), Stage 3 (combined products). Search via MAST Portal, MAST API, or exo.MAST.

[21] ESA Hubble Archive (eHST). https://hst.esac.esa.int/ehst/  
Tier 1. Mirrors MAST HST data. All calibration levels. No login for public data.

[22] ESASky Portal. https://sky.esa.int/  
Tier 1. Discovery portal covering ESA missions. 500,000+ images in FITS. No login required.

[23] ESA/Hubble Educational FITS Datasets. https://esahubble.org/projects/fits_liberator/datasets/  
Tier 1. Curated PSD+FITS datasets for education. Free, no login.

[24] NOIRLab Astro Data Archive. https://astroarchive.noirlab.edu/  
Tier 1. Data from 40+ telescope/instrument combinations. Compressed FITS (.fits.fz). No account needed for public data.

[25] SDSS Data Release 18. https://www.sdss.org/dr18/  
Tier 1. Photometric and spectroscopic survey. FITS imaging frames via SkyServer. No registration.

[26] ESO Science Archive. https://archive.eso.org/cms/eso-data.html  
Tier 1. VLT and La Silla raw data. ~20 million FITS files. CC-BY license after proprietary period.

[27] Chandra X-ray Observatory Data Archive. https://cxc.harvard.edu/cda/  
Tier 1. Public X-ray FITS data.

[28] Chandra OpenFITS. https://chandra.harvard.edu/photo/openFITS/  
Tier 1. Curated FITS datasets with tutorials.
