### Issue 2: Multilingual Degradation "8-29 Points"

**Severity:** MINOR
**Category:** Estimation Markers
**Status:** OPEN
**File:** `prompt-injection-defenses.md` (line ~146)

The deliverable states "Multilingual robustness (performance degrades 8-29 points) [15]." The reference file (detection-monitoring.md, line ~46) provides the underlying data: Meta Prompt Guard TPR drops from 99.9% (in-distribution jailbreak) to 91.5% (multilingual jailbreak) = 8.4 points, and from 99.5% (in-distribution injection) to 71.4% (CyberSecEval indirect) = 28.1 points.

**Expected:** The "29 points" figure appears derived from 99.5% - 71.4% = 28.1, but the CyberSecEval drop is not strictly a multilingual degradation — it is an out-of-distribution evaluation on indirect injections. The "8 points" is 99.9% - 91.5% = 8.4 points (this IS multilingual).
**Actual:** "8-29 points" conflates multilingual degradation (8.4 pts) with a different evaluation axis (indirect injection, 28.1 pts).
**Assessment:** The range mixes two distinct phenomena. Only the 8.4-point drop is strictly multilingual. Should be flagged as "(est.)" or clarified.
**Grade:** FAIL (minor — potentially misleading range)
