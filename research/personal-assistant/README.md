# Personal Assistant Software: Advisory PA for Developer Workflows

## TL;DR

**No existing tool** matches a read-only/advisory PA that aggregates Jira, GitHub, Google Workspace, Slack, and Claude into prioritized action lists without autonomous action. The market favors autonomous agents.

**Recommendation: Build it** using Claude API + pre-built MCP servers.

| Path | Monthly Cost | Setup Time | Privacy Control |
|------|-------------|------------|-----------------|
| **Build (Claude API + MCP)** | **$6-13** (API only; Haiku: $2-4) | 4-10 weeks | Full — data touches only Anthropic + platform APIs |
| Buy (Dume.ai Pro) | $18 | Hours | Partial — third-party data processor |
| Hybrid (Claude Cowork) | $20 | 1-2 weeks | Weaker — consumer account privacy defaults |
| Enterprise (Glean) | $50+/user | Months | Vendor-dependent |

## Key Findings

| Finding | Detail |
|---------|--------|
| MCP servers exist for all 4 data-source platforms | Atlassian (official, GA), GitHub (official, `--read-only`), Google Workspace (community, 100+ tools), Slack (official GA + community read-only default). Claude is the 5th platform but serves as the reasoning layer. |
| Build effort is orchestration, not integration | Pre-built servers handle API connectivity; you write the summarization prompt and glue |
| Claude Agent SDK built for this | Explicitly lists "personal assistant agents" as a use case |
| Privacy is achievable | API: 7-day retention, no training, SOC 2 Type II. Data path: local machine → platform APIs → Claude API. No intermediaries. |
| Slack rate limits are a constraint | Non-Marketplace apps: 1 req/min on `conversations.history` as of March 2026 |

## Quick Decision Framework

1. **Want it today?** → Claude Pro ($20/mo) + Cowork daily briefing. Works in hours, not weeks.
2. **Want full control + privacy?** → Claude API + Agent SDK + read-only MCP servers. 4-10 weeks to build.
3. **Want zero build effort?** → Dume.ai Pro ($18/mo) covers all integrations but isn't purely advisory.
4. **Enterprise with budget?** → Glean ($50+/user/mo) is search-first and advisory, but requires sales engagement.
