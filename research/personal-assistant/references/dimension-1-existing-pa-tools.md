## Tool Inventory

### 1. Claude Cowork (Anthropic)

- **What it does:** Desktop workspace that connects to tools via connectors, generates scheduled daily briefings as HTML dashboards. Scans email, calendar, Slack, Sentry, and other sources each morning. Produces a structured briefing organized by priority with cross-platform context synthesized into single items.
- **Integrations:** Gmail, Google Calendar, Google Drive, Slack, GitHub, Canva, and other natively supported connectors. Atlassian plugin provides Jira, Confluence, and Compass access.
- **Read-only/advisory mode:** Yes — the daily briefing use case is inherently advisory. Claude Cowork generates an HTML dashboard of priorities and action items. It reads from connected sources and produces a report. It CAN take actions if instructed, but the briefing workflow is read-only by design.
- **Pricing:** Requires Claude Pro ($20/month minimum). A daily briefing plus light usage fits within Pro. Intensive all-day use requires Max ($100-200/month).
- **Limitations:** Scheduled tasks only run while computer is awake and Claude Desktop is open. Sessions start fresh (no persistent memory without context files). Each complex Cowork task consumes as much quota as dozens of regular chat messages.
- **Source URLs:**
  - https://claude.com/resources/use-cases/build-a-daily-briefing-across-your-tools (accessed 2026-03-26)
  - https://petrvojacek.cz/en/blog/claude-cowork-daily-briefing/ (accessed 2026-03-26)
  - https://claude.com/product/cowork (accessed 2026-03-26)
- **Quality notes:** The Claude resource page is first-party documentation. The Petr Vojacek blog post is a personal experience report with specific detail about setup and costs.

## Key Finding: Gap in the Market

**No single tool was found that perfectly matches the described use case** — a read-only/advisory PA that aggregates across Jira, GitHub, Google Workspace, Slack, AND Claude to produce daily action lists without autonomous action.

The closest matches are:
1. **Claude Cowork** — best fit for the advisory briefing model, but requires Claude Desktop running on a local machine and is limited to personal use (not team-shareable)
2. **Dume.ai** — has daily briefings and all five integrations, but designed to also take actions
3. **Glean** — search-first advisory model with all integrations, but enterprise pricing makes it impractical for individual/small team use

This gap validates the potential value of building a custom solution.
