## Typosquatting

Attackers register package names that are deliberate misspellings of popular packages.

| Incident | Registry | Scale | Year |
|----------|----------|-------|------|
| PyPI mass typosquatting | PyPI | 500+ packages, forced registration suspension | March 2024 [SC-1] |
| 900 typosquats campaign | PyPI | 900 packages targeting 40 popular libraries | 2023 [SC-2] |
| "solana-py" | PyPI | Stole crypto wallet keys via naming mismatch | 2024 [SC-3] |
| "crossenv" | npm | Malicious postinstall script stole env vars | 2017 [SC-4] |
| Lazarus Group campaign | npm/PyPI | 234 packages, 36,000+ potential victims | 2024 [SC-5] |

PyPI removed 12,000 packages in 2022 and suspended new user registrations multiple times in late 2023 and early 2024 [SC-1].

## Dependency Confusion

Exploits package managers prioritizing public packages over private/internal packages of the same name.

**Original research:** Alex Birsan, February 2021 [SC-6]
- Breached 35 companies including Microsoft, Apple, PayPal, Shopify, Netflix, Tesla, Uber
- Earned over $130,000 in bug bounties ($40K Microsoft, $30K Apple, $30K PayPal, $30K Shopify, $15K Yelp)
- Named #1 in PortSwigger's Top 10 Web Hacking Techniques of 2021
- Attack remains viable — Netflix dependency confusion vulnerability documented in 2025 [SC-7]

## Star-Jacking and Fake Popularity

**Star-jacking** [SC-13]: Package registries let publishers link any GitHub repo without ownership verification. 3.03% of PyPI packages and 7.23% of npm packages have non-unique Git references (potential star-jacking candidates).

**Fake GitHub stars** [SC-14]: Carnegie Mellon researchers found 6 million suspected fake stars across 26,254 repositories. At peak (July 2024), >16% of starred repos were associated with fake star campaigns. Tool: StarScout detected 81.23% of known malicious network repos.

## Protestware and Intentional Sabotage

**colors.js / faker.js** (January 2022) [SC-19]: Developer Marak Squires intentionally corrupted packages (~20M weekly downloads) in protest against Fortune 500 companies using OSS without financial support.

**node-ipc / peacenotwar** (March 2022) [SC-20]: Developer added code that overwrote all files with a heart character on systems with Russian or Belarusian IPs (CVE-2022-23812). Affected Vue.js CLI users downstream.

## Install Scripts as Attack Vectors

npm lifecycle hooks (`preinstall`, `install`, `postinstall`) execute arbitrary code with full developer privileges during `npm install` [SC-21]:

- **Shai-Hulud** (September 2025): Compromised `ngx-bootstrap`, `ng2-file-upload`, `@ctrl/tinycolor`. Self-replicating worm harvesting credentials [SC-22].
- **SHA1-Hulud** (November 2025): 796 packages, 132 million monthly downloads. Installed backdoors and wiped environments [SC-22].

**Key gap:** npm does not require published code to match linked GitHub repository code [SC-21].

**Mitigations:** `npm install --ignore-scripts`, LavaMoat `allow-scripts`, pnpm blocks scripts by default [SC-21].

## AI-Specific: Slopsquatting

**Paper:** "We Have a Package for You!" — Spracklen et al., USENIX Security 2025 [SC-23]
- 576,000 code samples across 16 LLMs
- Average hallucinated package rate: 5.2% (commercial), 21.7% (open-source)
- 205,474 unique hallucinated package names
- 58% of hallucinated packages repeated across re-runs (exploitable)
- Reasoning-enhanced agents (Claude Code, Codex CLI) reduce but do not eliminate hallucinations

**Attack:** Register hallucinated package names with malicious code; developers who get the same hallucination install malware [SC-23].

## Gaps and Limitations

- Sonatype statistics are self-reported by a vendor with commercial interest in the problem space [SC-15]
- The $130,000 bug bounty total for Birsan's research is widely reported but per-company breakdowns beyond the top 5 are not publicly confirmed [SC-6]
- Shai-Hulud/SHA1-Hulud statistics (796 packages, 132M downloads) come from 2025 reporting and should be verified against primary advisories [SC-22]
- The "1.2% of PyPI packages are malicious" figure appeared in one search result and needs verification [SC-18]
