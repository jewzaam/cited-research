## T1 — Anthropic first-party documentation and support

1. **Claude Code — Authentication.** Anthropic. <https://code.claude.com/docs/en/authentication>
   (also reached via 301 from `https://docs.anthropic.com/en/docs/claude-code/iam` and
   `https://docs.claude.com/en/docs/claude-code/iam`).
   Data extracted: `CLAUDE_CODE_OAUTH_TOKEN` documented as "a long-lived OAuth
   token generated by `claude setup-token`," explicit "one-year OAuth token"
   wording for `claude setup-token`, full credential-precedence list (6 entries),
   credential storage paths (macOS Keychain, `~/.claude/.credentials.json`,
   `%USERPROFILE%\.claude\.credentials.json`), `apiKeyHelper` refresh semantics
   ("called after 5 minutes or on HTTP 401 response", `CLAUDE_CODE_API_KEY_HELPER_TTL_MS`),
   `--bare` mode exclusion of `CLAUDE_CODE_OAUTH_TOKEN`, scope claim ("scoped to
   inference only and cannot establish Remote Control sessions"), Agent SDK
   credit-pool transition note for June 15 2026. Tier 1.

2. **Claude Code — Environment variables.** Anthropic. <https://code.claude.com/docs/en/env-vars>
   Data extracted (verbatim, this is the decisive source for Q1 and Q4):
   - `CLAUDE_CODE_OAUTH_TOKEN`: "OAuth **access token** for Claude.ai
     authentication. Alternative to `/login` for SDK and automated environments.
     Takes precedence over keychain-stored credentials. Generate one with `claude setup-token`"
   - `CLAUDE_CODE_OAUTH_REFRESH_TOKEN`: "OAuth refresh token for Claude.ai
     authentication. When set, `claude auth login` exchanges this token directly
     instead of opening a browser. Requires `CLAUDE_CODE_OAUTH_SCOPES`. Useful for
     provisioning authentication in automated environments"
   - `CLAUDE_CODE_OAUTH_SCOPES`: "Space-separated OAuth scopes the refresh token
     was issued with, such as `\"user:profile user:inference user:sessions:claude_code\"`.
     Required when `CLAUDE_CODE_OAUTH_REFRESH_TOKEN` is set"
   Tier 1.

3. **Claude Code — Advanced setup.** Anthropic. <https://code.claude.com/docs/en/setup>
   (also at `docs.anthropic.com/en/docs/claude-code/setup` via redirect).
   Data extracted: pointer to `/en/authentication` for auth setup; `claude --version`
   and `claude doctor` for verification; no additional OAuth detail. Tier 1.

4. **Agent SDK overview.** Anthropic. <https://code.claude.com/docs/en/agent-sdk/overview>
   (reached via 307 from `https://platform.claude.com/docs/en/api/agent-sdk/overview`
   and 301 from `https://docs.claude.com/en/api/agent-sdk/overview`).
   Data extracted: SDK auth = `ANTHROPIC_API_KEY` (or cloud provider env var);
   verbatim restriction: "Unless previously approved, Anthropic does not allow
   third party developers to offer claude.ai login or rate limits for their
   products, including agents built on the Claude Agent SDK. Please use the API
   key authentication methods described in this document instead." No quota API
   endpoint mentioned. Tier 1.

5. **Use the Claude Agent SDK with your Claude plan.** Anthropic Help Center.
   <https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan>
   Data extracted: monthly Agent SDK credit pool sizes per plan (Pro $20, Max 5x
   $100, Max 20x $200, Team Standard $20 / Premium $100, Enterprise usage-based
   $20 / seat-based Premium $200); drain order ("Agent SDK usage draws from your
   monthly credit before any other source"); zero-credit behavior; monthly reset
   at billing cycle, no rollover; statement that Agent SDK + `claude -p` "no
   longer counts toward your Claude plan's usage limits" while interactive
   Claude Code continues to use subscription limits. No credit-balance API
   endpoint documented. Tier 1.

6. **Use Claude Code with your Pro or Max plan.** Anthropic Help Center.
   <https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-or-max-plan>
   Data extracted: `/status` documented as the surface for "Monitor your remaining
   allocation"; "usage limits are shared across Claude and Claude Code, meaning
   all activity in both tools counts against the same usage limits";
   `ANTHROPIC_API_KEY` precedence warning. No quota REST endpoint mentioned. Tier 1.

7. **How do usage and length limits work?** Anthropic Help Center.
   <https://support.claude.com/en/articles/11647753-how-do-usage-and-length-limits-work>
   Data extracted: "your usage of all different Claude product surfaces (claude.ai,
   Claude Code, Claude Desktop) counts towards the same usage limit"; page does
   not enumerate 5-hour window mechanics or quota visibility surfaces. Tier 1.

8. **Rate limits — Claude API.** Anthropic. <https://platform.claude.com/docs/en/api/rate-limits>
   Data extracted: full `anthropic-ratelimit-*` response-header table (requests,
   tokens, input-tokens, output-tokens — each with limit/remaining/reset; plus
   `anthropic-priority-*` headers for Priority Tier); token-bucket algorithm
   wording; 429 + `retry-after` behavior; pointer to Rate Limits API for
   programmatic readback. Scope of page is API rate limits (org-level usage
   tiers), not subscription quota. Tier 1.

9. **Rate Limits API.** Anthropic. <https://platform.claude.com/docs/en/build-with-claude/rate-limits-api>
   Data extracted: endpoint paths
   `GET https://api.anthropic.com/v1/organizations/rate_limits` and
   `GET https://api.anthropic.com/v1/organizations/workspaces/{workspace_id}/rate_limits`;
   verbatim auth requirement: "Admin API key required. This API is part of the
   Admin API. These endpoints require an Admin API key (starting with `sk-ant-admin...`)
   that differs from standard API keys. Only organization members with the admin
   role can provision Admin API keys through the Claude Console." Returns
   configured rate limits per model group / batch / files / etc; does NOT
   return current consumption or subscription counters. Tier 1.

## T2 — Anthropic-org GitHub repository (`anthropics/claude-code`)

> Per the user-set tier constraint, only Anthropic-org repos count. Issue
> *bodies* are community-submitted reports but are filed against the
> first-party project. Used only for behavior captured from the official
> CLI binary's own logs (Q2 endpoint URL, observed scopes, refresh failure
> modes). Where these confirm or extend T1 documentation, the citation
> remains; where they substitute for missing T1 docs (Q4 rotation), the
> claim is explicitly labeled "unverified by first-party documentation."

10. **Issue #54443 — "OAuth refresh returns 400 after early 401 before local
    expiresAt; concurrent sessions forced to /login."** anthropics/claude-code.
    State: OPEN. Labels: `area:auth`, `bug`, `has repro`, `platform:linux`.
    <https://github.com/anthropics/claude-code/issues/54443>
    Data extracted: **exact URL of the OAuth refresh endpoint** as observed in
    debug logs from Claude Code 2.1.121 native binary:
    `POST https://platform.claude.com/v1/oauth/token`. Refresh response: `400`.
    Subscription type: Max. References issues #52202 (early-revocation refresh
    path, partial fix in v2.1.118) and #24317 (refresh-token race). Tier 2.

11. **Issue #24317 — "Frequent re-authentication required with multiple
    concurrent Claude Code sessions (OAuth refresh token race condition)."**
    anthropics/claude-code. State: CLOSED. Labels: `area:auth`, `bug`, `has repro`.
    <https://github.com/anthropics/claude-code/issues/24317>
    Data extracted: `~/.claude/.credentials.json` contains `accessToken` (short-lived,
    ~15h per reporter), `refreshToken`, `expiresAt`. Community analysis describes
    refresh-token rotation: "OAuth refresh tokens are typically single-use:
    when one process uses the refresh token to get a new access/refresh token
    pair, the old refresh token is invalidated server-side." Reproducible race
    when N concurrent processes share the credential file. Tier 2.

12. **Issue #42904 — "OAuth access token not auto-refreshed — daily re-login
    required for subscription users."** anthropics/claude-code.
    State: CLOSED (duplicate). <https://github.com/anthropics/claude-code/issues/42904>
    Data extracted: sanitized `~/.claude/.credentials.json` shape:
    `{"claudeAiOauth": {"accessToken": ..., "refreshToken": ..., "expiresAt": ...,
    "scopes": ["user:file_upload","user:inference","user:mcp_servers",
    "user:profile","user:sessions:claude_code"], "subscriptionType": "pro",
    "rateLimitTier": "default_claude_ai"}}`. Interactive `/login`-issued access
    tokens observed at ~24-hour TTL. Tier 2.

13. **Issue #52202 — "[DOCS] Authentication docs omit OAuth refresh behavior when
    the server revokes a token early."** anthropics/claude-code. State: OPEN.
    Labels: `area:auth`, `documentation`, `enhancement`.
    <https://github.com/anthropics/claude-code/issues/52202>
    Data extracted: verbatim **Anthropic changelog v2.1.118 entry** (quoted in
    the issue): "Fixed OAuth token refresh failing when the server revokes a
    token before its local expiry time." Issue body confirms the env-vars page
    documents `CLAUDE_CODE_OAUTH_REFRESH_TOKEN`, `CLAUDE_CODE_OAUTH_SCOPES`, and
    `CLAUDE_CODE_OAUTH_TOKEN` independently. Tier 2.

14. **Issue #10715 — "Anthropic API Error: Internal Server Error on OAuth
    Reauthentication."** anthropics/claude-code. State: CLOSED (duplicate).
    <https://github.com/anthropics/claude-code/issues/10715>
    Data extracted: OAuth authorization URL captured in bug log:
    `https://claude.ai/oauth/authorize?...client_id=9d1c250a-e61b-44d9-88ed-5944d1962f5e&response_type=code&redirect_uri=https%3A%2F%2Fconsole.anthropic.com%2Foauth%2Fcode%2Fcallback&scope=org%3Acreate_api_key+user%3Aprofile+user%3Ainference&code_challenge_method=S256...`
    Tier 2.

15. **Issue #28091 — "Anthropic disabled OAuth tokens for third-party apps."**
    anthropics/claude-code. State: CLOSED (duplicate).
    <https://github.com/anthropics/claude-code/issues/28091>
    Data extracted: token prefix format (verbatim from report): OAuth tokens
    from `claude setup-token` prefix `sk-ant-oat01-*`; Console API keys prefix

16. **Issue #33820 — "Expose API rate-limit response headers to hooks and status

    returned by the Anthropic API but are NOT exposed by Claude Code to hooks
