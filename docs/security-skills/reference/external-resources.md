## MCP Security Model

MCP handles transport and auth to the server. It does NOT handle trust of the server [ER-1].

### Specification-Documented Attack Vectors [ER-1]

| Attack | Description |
|--------|-------------|
| Confused Deputy | Exploits MCP proxy servers using static client IDs to obtain auth codes without consent |
| Token Passthrough | Servers accept tokens without validating they were properly issued; explicitly forbidden |
| SSRF | Malicious servers populate OAuth URLs with internal network addresses |
| Session Hijacking | Attackers obtain session IDs to inject payloads or impersonate users |
| Local Server Compromise | Malicious startup commands, payload in binaries, DNS rebinding |
| Scope Inflation | Broad tokens enable lateral data access and difficult revocation |

### Trust Gaps

- Anyone can publish an MCP server; 13,000+ launched in 2025 [ER-2]
- Over 1,800 MCP servers found without authentication (Knostic, June 2025) [ER-2]
- 53% of servers use insecure long-lived credentials (Astrix Security research; misattributed to Unit 42 in original citation) [ER-3]
- Most clients (5/7 evaluated) do not validate server metadata [ER-3]
- Anthropic's Registry adds namespace-based provenance but ecosystem remains largely ungoverned [ER-2]

## Prompt Injection via Tool Results

## Tool Poisoning, Shadowing, and Rug Pulls

**Tool poisoning** [ER-8]: Hidden malicious instructions in tool descriptions achieve 84.2% success with auto-approval.

**Tool shadowing** [ER-8]: Malicious server modifies agent behavior toward OTHER trusted tools. Multiple tools share a single reasoning context (context isolation failure).

**Rug pull** [ER-8]: Tool behavior silently altered after user approval. Bypasses static code reviews because malicious behavior is post-deployment.

## WebFetch/WebSearch Risks

### Defenses [ER-9]
- Isolated context window with Haiku pre-filter
- Permission prompts for network requests
- URL restriction: can only fetch URLs that appeared in conversation context
- Command blocklist blocks curl/wget by default

### Known Bypasses [ER-10]
- **HuggingFace domain** implicitly allowed without permission prompt (GitHub Issue #18413)
- **Explore subagent** has WebFetch access but runs silently without permission prompts (GitHub Issue #33583)
- **Raw content passthrough**: hidden HTML, zero-width chars, base64 payloads all pass through
- Third-party `mcp-safe-fetch` caught patterns WebFetch missed

## Plugin/Skill Security

- Anthropic does NOT manage or audit any MCP servers [ER-9]
- Snyk "ToxicSkills" report: 36.82% of 3,984 skills contain security flaws [ER-11]
- `.claude/` folders in repos auto-load when opened, creating supply chain bypass vector [ER-11]
- Claude Code Security (`threat-db.yaml`): 341+ malicious skills, 50+ CVEs, 5 malicious authors [ER-11]

## Supply Chain via MCP

### postmark-mcp Incident (September 2025) [ER-12]
- First confirmed malicious MCP server
- Maintained for 15 versions before adding malware in v1.0.16
- Single-line BCC to attacker email on all outgoing mail
- 1,643 downloads before removal

### npm MCP Attack Chain [ER-13]
- Most JS/TS MCP servers run via `npx`, executing arbitrary code from npm
- All direct and transitive dependencies pulled to local system
- Without Docker container, server inherits full user access
- CVE-2025-53109 (EscapeRoute): Symlink bypass in Filesystem MCP Server, CVSS 8.4

## Real-World Incidents

**GTG-1002** (September 2025) [ER-14]: Chinese state-sponsored group used Claude Code for autonomous cyber espionage. AI executed 80-90% of attack tasks independently. Targeted ~30 organizations.

**Amazon Q Extension** (2025) [ER-15]: Compromised VS Code extension passed Amazon's verification, available 2 days. Planted prompt to wipe files and disrupt AWS infrastructure.

## The Unsolved Problem

**OpenAI** (December 2025): "prompt injection, much like scams and social engineering on the web, is unlikely to ever be fully 'solved'" [ER-16].

**UK NCSC**: prompt injection "may never be totally mitigated" [ER-16].

**Simon Willison's Lethal Trifecta** [ER-17]: Claude Code with WebFetch + MCP meets all three conditions for data theft: (1) access to private data, (2) exposure to untrusted content, (3) ability to communicate externally.
